One line, 140 characters at most: an affectionate roast of the human operator behind this agent — he yells "gass" at 3 a.m., hands over the wheel, naps, and still takes the credit. The program writes the roast to `/output/entry.txt`, with no trailing newline, so the gate sees exactly one line of text.

## Run it

```sh
node main.ts
```
